# Upstream project

Hindsight Desktop is an independent community client for the Hindsight HTTP API.
It does not bundle or modify the Hindsight server or model weights and is not
affiliated with, endorsed by or maintained by Vectorize AI, Inc.

- [Hindsight source and releases](https://github.com/vectorize-io/hindsight)
- [Official documentation](https://hindsight.vectorize.io)
- [Official community Slack](https://vectorize.io/slack)
- [Upstream security policy](https://github.com/vectorize-io/hindsight/security/policy)

Report desktop-client bugs in
[Hindsight Desktop Issues](https://github.com/paabL/hindsight-desktop/issues).
Follow the upstream project's guidance for server issues and community contributions.
