# Contact avec l'équipe Hindsight

Canal officiel proposé par le dépôt upstream : [communauté Slack](https://vectorize.io/slack).
Le [dépôt Hindsight](https://github.com/vectorize-io/hindsight) propose aussi des
discussions publiques. Envoyer après la disponibilité d'une release vérifiée.

## Message prêt à envoyer

Hi Hindsight team — I built a small independent macOS desktop client for
Hindsight, with a React/Tauri interface and a native Swift API client.
The first release is a free MIT-licensed community beta:
https://github.com/paabL/hindsight-desktop

It focuses on reviewing local sources, searching memories, and managing a
Hindsight server with explicit confirmation before uploads and destructive
actions. It is a separate API client; it does not bundle or modify your server
or model weights. The README clearly states that it is unofficial and credits
Vectorize and the upstream project.

I'd appreciate feedback on compatibility and the use of the Hindsight name.
Is there a preferred place to list community integrations or discuss API
changes? Happy to adjust the naming and links to avoid any confusion.

Thanks — Pablo
